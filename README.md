# STOtesel — сайт автосервісу

Astro + Cloudflare Workers + Supabase. Дизайн, тексти й поведінка взяті з макета `stotesel.html`.

## Запуск локально

```bash
npm install
```

```bash
npm run dev
```

- Сайт: http://localhost:4321
- Адмінка: http://localhost:4321/admin (пароль лежить у файлі `.dev.vars`, рядок `ADMIN_PASSWORD`)

Поки змінні Supabase не задані, сайт працює в демо-режимі: дані зберігаються локально в `.wrangler/state`. Щоб повернути початковий стан, зупиніть сервер і видаліть цю папку.

## Сторінки

| Адреса | Що це |
| :--- | :--- |
| `/` | Головна з блоків макета: перший екран, марки, прайс, кроки, переваги, запис, питання, контакти |
| `/poslugy/` | Усі послуги картками |
| `/<slug>/` | Окрема сторінка кожної послуги, напр. `/planove-to/`, з формою запису |
| `/tsiny/` | Повний прайс |
| `/zapchastyny/` | Запчастини картками за категоріями |
| `/kontakty/` | Контакти, карта, маршрут |
| `/admin` | Адмінка |
| `/sitemap.xml`, `/robots.txt`, 404 | Службові |

## Що редагується в адмінці

- **Заявки**: записи з форми, статус (нова, підтверджена, виконана, скасована). Скасування звільняє слот.
- **Розклад**: типовий тиждень (час візитів по днях) і винятки на конкретний день: закрити слот, додати час, зробити вихідний.
- **Послуги і ціни**: назва, адреса сторінки, ціна «від», тривалість, опис, перелік робіт, SEO. Ціну можна міняти прямо в списку.
- **Запчастини**: назва, категорія, опис, ціна, наявність.
- **Головна сторінка**: порядок блоків, показати або сховати, усі тексти. Можна додати текстовий блок, банер, відгуки.
- **Налаштування**: назва, телефон, адреса, графік, месенджери, адреса сайту, SEO головної.

Зміни видно на сайті одразу: сторінки рендеряться на Worker при кожному запиті.

## Як влаштовано

- `src/lib/seed.ts` — початкові дані з макета.
- `src/lib/store.ts` — доступ до даних: Supabase або локальне демо-сховище.
- `src/lib/schedule.ts` — розрахунок вільних слотів (час за Києвом).
- `src/styles/site.css` — стилі макета без змін; `extra.css` — стилі нових сторінок.
- `src/components/admin/AdminApp.tsx` — адмінка (React + Tailwind).
- `src/pages/api/` — слоти, запис, адмінка.
- `supabase/schema.sql` — схема бази.

## Підключення Supabase

1. Створіть проєкт у Supabase і виконайте `supabase/schema.sql` у SQL Editor.
2. Додайте в `.dev.vars` значення `SUPABASE_URL` і `SUPABASE_SERVICE_ROLE_KEY` (Project Settings → API).
3. Перезапустіть `npm run dev` і зайдіть в адмінку: початкові дані перенесуться в базу самі.

Ключ service role використовується тільки на сервері й у браузер не потрапляє.

## Telegram і Turnstile (пізніше)

Код уже є, він вмикається, щойно задані змінні (перелік у `.dev.vars.example`):

- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — кожна нова заявка приходить у чат.
- `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY` — перевірка форми запису від ботів.

## Деплой на Cloudflare

```bash
npx wrangler login
```

Секрети задаються по одному: `ADMIN_PASSWORD`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, за потреби Telegram і Turnstile.

```bash
npx wrangler secret put ADMIN_PASSWORD
```

```bash
npm run deploy
```

Після підключення домену впишіть його в адмінці: Налаштування → Адреса сайту. Від цього залежать canonical, sitemap і розмітка.
